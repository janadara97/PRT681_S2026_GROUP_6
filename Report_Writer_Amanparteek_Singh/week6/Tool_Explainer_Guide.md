# Tool Explainer Guide

*Simple, Technical, and Mixed definitions for each tool.*

---

## JIRA

**Simple:** JIRA is like a big digital to-do board that a whole team shares. Every task gets its own little card, and the card moves from "Not Started" to "Doing" to "Done" as the work gets finished. It helps everyone see who is doing what, without anyone needing to ask around or send a bunch of messages.

**Technical:** JIRA is an issue and project-tracking tool built by Atlassian, used to manage software development workflows. It supports customizable workflows, issue types (epics, stories, tasks, bugs), sprints, backlogs, and Agile/Scrum or Kanban boards, with reporting features like burndown charts and velocity tracking for release planning.

**Mixed:** JIRA is a tool that teams use to plan, track, and manage work items called "issues" (tasks, bugs, stories). Think of it as a shared task board where each piece of work moves through stages like To Do, In Progress, and Done. It supports Agile methods like Scrum and Kanban, so teams can plan sprints and track progress over time.

---

## Confluence

**Simple:** Confluence is like a big shared notebook for a team. Instead of everyone keeping notes on their own computer, everyone writes and reads pages in one place online. You can write meeting notes, plans, or instructions, and anyone on the team can find them later.

**Technical:** Confluence is a collaborative wiki and knowledge-management platform by Atlassian used for creating, organizing, and linking documentation. It supports structured spaces, page hierarchies, macros, version history, and integrates directly with JIRA for linking requirements, specs, and project documentation to tracked issues.

**Mixed:** Confluence is a workspace where teams write and store documents, notes, and plans as web pages instead of files. Pages are organized into "spaces" and can be linked to JIRA tickets, so documentation and project tracking stay connected. It's commonly used for meeting notes, requirements docs, and internal wikis.

---

## Visio

**Simple:** Visio is a program for drawing pictures that explain how things connect or flow, like a map of steps in a process or a chart of who reports to whom. Instead of drawing by hand, you drag ready-made shapes onto a page and connect them with lines.

**Technical:** Microsoft Visio is a diagramming application used to create flowcharts, network diagrams, organizational charts, floor plans, and UML diagrams using a shape-stencil library, with support for data linking to Excel to auto-generate or update diagrams from underlying datasets.

**Mixed:** Visio is Microsoft's diagramming tool for creating flowcharts, process maps, org charts, and network diagrams. You drag pre-built shapes onto a canvas and connect them, and you can even link the diagram to a spreadsheet so it updates automatically when the data changes.

---

## Draw.io

**Simple:** Draw.io (also called diagrams.net) does the same job as Visio, but it's free and works right in your web browser. You drag shapes and boxes onto a page and connect them with arrows to show how a process or system works.

**Technical:** Draw.io / diagrams.net is a free, open-source diagramming tool that runs in the browser or as a desktop app, supporting flowcharts, network diagrams, and wireframes, with native integrations for Confluence, Google Drive, and GitHub for storing and version-controlling diagram files.

**Mixed:** Draw.io (diagrams.net) is a free flowchart and diagramming tool similar to Visio but browser-based and open source. It's popular because it integrates directly with tools like Confluence and Google Drive, so diagrams can be embedded and edited without extra software or licensing cost.

---

## Trello

**Simple:** Trello is like a wall of sticky notes, but on a screen. You make a card for each task and stick it under a column like "To Do," "Doing," or "Done." You can drag the cards across as work moves along, so it's easy to see the whole picture at a glance.

**Technical:** Trello is a lightweight Kanban-style project management tool built around boards, lists, and cards. Cards support checklists, due dates, labels, attachments, and automation rules (via Butler), making it suited for simpler workflows compared to more feature-heavy tools like JIRA.

**Mixed:** Trello is a visual task-management tool based on boards, lists, and cards, following the Kanban method. It's simpler and more flexible than JIRA, making it popular for smaller teams or personal task tracking, with drag-and-drop cards, due dates, and basic automation.

---

## Microsoft Planner

**Simple:** Microsoft Planner is another to-do board, similar to Trello, but it comes built into Microsoft 365. You create tasks, assign them to people, set due dates, and watch a chart fill up as things get completed.

**Technical:** Microsoft Planner is a task-management app within Microsoft 365 that provides Kanban-style boards ("plans") with buckets, assigned tasks, labels, and due dates, plus built-in charts for tracking progress, and integrates with Teams and Microsoft 365 Groups for permissions and notifications.

**Mixed:** Microsoft Planner is a simple task-tracking tool inside Microsoft 365, offering Kanban boards for assigning and tracking tasks with due dates and progress charts. It's tightly integrated with Teams and Outlook, making it a natural choice for teams already using Microsoft 365.

---

## OneNote

**Simple:** OneNote is like a digital notebook you can carry everywhere. You can type notes, paste pictures, or even draw, and it's all organized into notebooks, sections, and pages just like a real binder, but you can search through everything instantly.

**Technical:** Microsoft OneNote is a free-form digital note-taking application organized into notebooks, sections, and pages, supporting text, ink/handwriting, images, audio, and embedded files, with real-time multi-user syncing via OneDrive and integration across the Microsoft 365 suite.

**Mixed:** OneNote is a digital notebook for capturing notes, screenshots, and ideas in a free-form layout, organized into notebooks, sections, and pages. It syncs through OneDrive so notes are available across devices and can be shared and edited with others in real time.

---

## Microsoft Office Suite

**Simple:** The Microsoft Office Suite is a bundle of programs you use every day at work or school, like Word for writing, Excel for numbers, and PowerPoint for presentations. It's basically a toolbox with a different tool for each kind of task.

**Technical:** Microsoft 365 (formerly Office) is a cloud-connected productivity suite comprising applications such as Word, Excel, PowerPoint, Outlook, and Teams, alongside cloud storage (OneDrive/SharePoint) and collaboration services, offered via subscription with continuous updates and cross-device syncing.

**Mixed:** The Microsoft Office Suite (now Microsoft 365) is the standard set of productivity apps — Word, Excel, PowerPoint, Outlook, Teams, and more — bundled together and connected through the cloud via OneDrive and SharePoint, so documents can be created, edited, and shared across devices.

---

## Outlook

**Simple:** Outlook is where you send and receive email, and it also has a calendar so you can keep track of meetings and reminders, all in one app.

**Technical:** Microsoft Outlook is an email client and personal information manager supporting email (via Exchange/IMAP), calendaring, contacts, and task management, with enterprise features like shared mailboxes, meeting scheduling, and rules-based mail automation.

**Mixed:** Outlook is Microsoft's email and calendar application, used for sending messages, scheduling meetings, and managing contacts and tasks. It connects to Exchange servers in workplace settings, enabling shared calendars, meeting invites, and mail rules for organizing an inbox.

---

## Teams

**Simple:** Teams is where you chat with coworkers and hop on video calls, kind of like a mix of texting and a video-call app, but built for work.

**Technical:** Microsoft Teams is a unified communication and collaboration platform offering persistent chat, video/audio conferencing, file sharing (via SharePoint), and channel-based team organization, with app integrations for tools like Planner, OneNote, and third-party services.

**Mixed:** Microsoft Teams is a chat and video-conferencing hub for team collaboration, organized into channels for different projects or topics. It integrates tightly with the rest of Microsoft 365, letting you share files, co-edit documents, and pull in apps like Planner directly inside a chat.

---

## Git

**Simple:** Git is like a save-history for code. Every time you make changes, Git remembers what it looked like before, so if something breaks, you can always go back to an earlier version. It also lets several people work on the same project without overwriting each other's work.

**Technical:** Git is a distributed version control system that tracks changes to source code through commits, enabling branching, merging, and history tracking. It allows multiple developers to work in parallel on separate branches and later merge changes, with full local repository history independent of a central server.

**Mixed:** Git is a version control system that tracks every change made to a project's files over time, letting developers save "snapshots" (commits), branch off to work on features separately, and merge their work back together without losing anyone's changes.

---

## GitHub

**Simple:** GitHub is a website that stores your Git projects online, so your team can see the code, discuss changes, and work together from anywhere, kind of like Google Drive but built specifically for code.

**Technical:** GitHub is a cloud-based hosting platform for Git repositories, providing collaboration features such as pull requests, code review, issue tracking, CI/CD pipelines (GitHub Actions), and access control, layered on top of the core Git version-control system.

**Mixed:** GitHub is an online platform for hosting Git repositories, adding collaboration tools on top of Git such as pull requests for code review, issue tracking, and automated pipelines. It's where teams store and manage their code together and coordinate changes before merging them.

---

## Bitbucket

**Simple:** Bitbucket does basically the same job as GitHub, storing team code online, just made by a different company (Atlassian) and often used alongside JIRA.

**Technical:** Bitbucket is Atlassian's Git repository hosting service, offering pull requests, code review, pipelines (CI/CD), and branch permissions, with tight native integration into JIRA for linking commits and pull requests to tracked issues.

**Mixed:** Bitbucket is a Git repository hosting platform similar to GitHub, made by Atlassian. It supports the same core Git commands and workflow, but is often chosen because it links directly to JIRA, connecting code changes to the tickets they relate to.

---

## SharePoint & OneDrive

**Simple:** SharePoint and OneDrive are places to store your files online instead of only on your computer, so you can open them from anywhere and share them with others easily. OneDrive is more for your personal files, and SharePoint is more for team or company files.

**Technical:** OneDrive is Microsoft's personal cloud storage service, while SharePoint is an enterprise content management and collaboration platform built for team sites, document libraries, permissions, and workflow automation; both use the same underlying storage engine and integrate throughout Microsoft 365.

**Mixed:** OneDrive and SharePoint are Microsoft's cloud storage services — OneDrive for individual file storage and syncing, SharePoint for shared team sites and document libraries with more advanced permissions and workflows. Both are included in Microsoft 365 and allow real-time co-authoring of files.

---

## Power BI

**Simple:** Power BI takes a big pile of numbers, like sales figures, and turns it into charts and graphs that are easy to understand at a glance, kind of like turning a boring spreadsheet into a colorful picture.

**Technical:** Power BI is a business intelligence and data visualization tool that connects to various data sources, transforms data using Power Query and DAX, and builds interactive dashboards and reports for analytics, supporting scheduled refresh and enterprise-level sharing through the Power BI Service.

**Mixed:** Power BI is Microsoft's data visualization and reporting tool. It connects to spreadsheets, databases, or other sources, lets you shape the data, and turns it into interactive dashboards and charts, so trends and insights are easier to spot than in a raw table of numbers.

---

## Lucidchart

**Simple:** Lucidchart is another online tool for drawing diagrams and flowcharts, similar to Visio or Draw.io, but it lives entirely in your web browser and is easy to use with a team.

**Technical:** Lucidchart is a cloud-based diagramming tool for creating flowcharts, wireframes, ER diagrams, and org charts, with real-time multi-user collaboration, data-linking capabilities, and integrations with platforms like Google Workspace, Slack, and Confluence.

**Mixed:** Lucidchart is a web-based diagramming tool, similar to Visio, used to build flowcharts, org charts, and process maps. It's built for real-time collaboration, so multiple people can edit the same diagram together, and it integrates well with tools like Confluence and Google Workspace.

---

## Microsoft Forms

**Simple:** Microsoft Forms lets you create simple online surveys or quizzes. You build a list of questions, share a link, and the answers people give get collected automatically so you don't have to count them by hand.

**Technical:** Microsoft Forms is a survey and quiz-building tool within Microsoft 365 that generates shareable web forms, collects responses in real time, and automatically compiles results into charts or an Excel spreadsheet for analysis.

**Mixed:** Microsoft Forms is a tool for building quick surveys, polls, or quizzes. You create questions, share a link, and responses are collected automatically and summarized in charts, or exported to Excel for deeper analysis.

---

## Excel

**Simple:** Excel is a program full of rows and columns where you can type in numbers or words and organize them into tables. It can also do the math for you and turn your numbers into simple charts.

**Technical:** Microsoft Excel is a spreadsheet application supporting formulas, functions, pivot tables, macros (VBA), and data visualization, widely used for data analysis, financial modeling, and reporting, with support for large datasets and integration with Power Query/Power BI.

**Mixed:** Excel is a spreadsheet program used to organize, calculate, and analyze data in rows and columns. Beyond basic tables, it supports formulas, pivot tables, and charts, and can handle everything from simple lists to complex financial models.

---

## Notepad++

**Simple:** Notepad++ is a simple program for writing and editing plain text, like a fancier version of the basic Notepad app on Windows, made especially for people who write code.

**Technical:** Notepad++ is a lightweight source code editor for Windows supporting syntax highlighting, plugins, multi-document tabbed editing, and regular-expression find/replace, making it a common tool for quick edits to code or configuration files.

**Mixed:** Notepad++ is a free, lightweight text editor popular for editing code and config files. It adds features like syntax highlighting, tabs for multiple open files, and powerful find-and-replace, without the overhead of a full development environment.

---

## PowerShell

**Simple:** PowerShell is a way to give your computer instructions by typing commands instead of clicking buttons, which lets you get repetitive tasks done much faster once you know the right commands.

**Technical:** PowerShell is a task automation and configuration management framework from Microsoft, combining a command-line shell with a scripting language built on the .NET framework, used for automating system administration tasks, managing services, and orchestrating Windows and cloud environments.

**Mixed:** PowerShell is a command-line and scripting tool used to automate tasks on Windows systems, such as managing files, services, or user accounts. It's more powerful than a basic command prompt because it's built on .NET and can handle complex scripts and automation.

---

## Batch Script

**Simple:** Batch scripts are short lists of commands saved in a file that you can run all at once, so instead of typing the same commands over and over, the computer does them automatically.

**Technical:** Batch scripting uses the Windows Command Prompt (cmd.exe) scripting language to automate sequences of commands via .bat files, commonly used for simple file operations, environment setup, and legacy automation tasks predating PowerShell.

**Mixed:** Batch scripting is an older, simpler way to automate tasks on Windows by writing a sequence of commands into a .bat file. It's less powerful than PowerShell but still useful for quick, simple automation like moving files or running a set of programs in order.
