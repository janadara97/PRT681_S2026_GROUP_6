# Tool Notes — Tools and Technologies for Report Writer

*Software Engineering Practice — Week 1 Deliverable | Charles Darwin University*

The tools below reflect the documentation-focused Report Writer role used in this project, drawn from the course brief and confirmed against real Australian job postings researched for this course (Seek, Indeed, Jora). The first group centres on writing, formatting, communication, and version control. A second group of BI/data-reporting tools (Power BI, Tableau, SQL, SSRS, Crystal Reports, Looker Studio, Zoho Analytics) is included for awareness, since some Australian "Reporting Analyst" listings blend documentation with data reporting — these are supplementary rather than core requirements for this role.

## Core Documentation Tools

| Tool / Technology | What It Is | Why It's Used | Example Use in This Role |
|---|---|---|---|
| Microsoft Word | Word processing software for drafting formal, long-form documents. | Industry-standard for formal reports, manuals, and academic submissions with heading styles, references, and page numbering. | Drafting the Career Research, Learning Plan, and final Week 1 report in this project. |
| Markdown | A lightweight, plain-text formatting syntax that renders as styled text. | Used for README files, GitHub documentation, and quick notes because it's fast to write and version-control friendly. | Writing the repository README.md and weekly meeting notes. |
| GitHub | A cloud-based version control platform for storing and tracking file changes. | Keeps a full history of document changes, supports team collaboration, and is the platform this course requires for submission evidence. | Uploading weekly documentation to individual folders with regular, incremental commits. |
| Microsoft Teams | A team communication and video-meeting platform. | Used for weekly group meetings, screen sharing, and quick file sharing between teammates. | Running the two weekly group meetings and recording them for absent members. |
| Microsoft Excel | Spreadsheet software for organising data into rows, columns, and tables. | Useful for structured tables such as skills matrices, timesheets, and simple tracking sheets. | Building the Skills & Resources table and tracking weekly individual/group hours. |
| Microsoft PowerPoint | Presentation software for slide-based visual communication. | Used when documentation needs to be presented to the team, lecturer, or stakeholders rather than just read. | Preparing a short slide summary of Week 1 findings for a team check-in. |
| Confluence / Notion | Cloud-based knowledge-base and documentation platforms. | Common in Australian workplaces for centralising documentation so teams aren't relying on scattered files. | Referenced in real job postings (e.g. Randstad Digital) as the platform documentation is distributed through. |
| Grammarly | An AI-assisted grammar, spelling, and clarity-checking tool. | Speeds up proofreading and catches errors before submission, which is a core Report Writer responsibility. | Running a final grammar and clarity pass over each Word document before committing it to GitHub. |
| AI Writing Tools (Claude, Copilot) | Generative AI assistants that help draft, edit, and structure written content. | Increasingly expected in real Technical Writer job ads (e.g. Randstad Digital listing) as a tool to support — not replace — documentation work. | Used in this project to help draft, organise, and proofread weekly documentation, with all factual claims checked against real sources. |

## BI / Data-Reporting Tools (Awareness-Level, Supplementary)

| Tool / Technology | What It Is | Why It's Used | Example Use in This Role |
|---|---|---|---|
| Power BI | A Microsoft business intelligence tool for building dashboards from data. | Not a core Report Writer tool, but some Australian "Reporting Analyst" listings blend documentation with light data reporting, so basic familiarity is a bonus. | Would be used only if a report required an embedded chart or dashboard screenshot rather than being built from scratch. |
| Tableau | A data visualisation and BI platform for building interactive dashboards and charts. | Appears in Australian job ads (e.g. Veolia's Business & Reporting Analyst listing) as an alternative to Power BI for translating data into visual reports. | Useful background knowledge if a report needs to reference or embed an existing Tableau dashboard rather than being built from raw data. |
| SQL | A query language used to retrieve and filter data stored in databases. | Underpins most BI/data-reporting roles; lets a reporting analyst pull the exact data a report needs rather than relying on manual exports. | Would be used to extract figures from a database before writing them up in a report, in Data/Reporting Analyst-style roles. |
| SQL Server Reporting Services (SSRS) | A Microsoft server-based tool for creating, publishing, and managing formatted business reports. | Common in government and enterprise environments for standardised, recurring reports (e.g. monthly compliance reports). | Referenced in industry job ads as a "BI Report Writer" tool alongside Power BI and Crystal Reports. |
| Crystal Reports | A long-established report-design tool for building formatted, print-ready business reports from data sources. | Still used in some government, finance, and legacy enterprise systems for standardised statutory or financial reporting. | Would appear in more traditional "Report Writer/Developer" roles that focus on structured, recurring business reports. |
| Google Looker Studio | A free, browser-based dashboard and reporting tool from Google (formerly Data Studio). | A no-cost alternative to Power BI/Tableau for building shareable dashboards, popular with smaller organisations and students. | A low-cost way to practise dashboard-style reporting skills without needing a paid Power BI or Tableau licence. |
| Zoho Analytics | A cloud-based BI and analytics platform for building reports and dashboards. | Appears in some Australian and international BI-focused report writer/developer job ads as a lighter-weight alternative to Power BI. | Awareness-level only — useful to recognise if it comes up in a job ad, not essential for the documentation-focused Report Writer role. |
